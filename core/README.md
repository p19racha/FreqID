# freqid-core

## Purpose
Core inference library for FreqID. This module wraps the frequency-domain CNN backbone and feature extraction pipelines.

## Target Phase
**Phase 2**: freqid-core inference library.

## Notes
The original TFace repository code remains in place at `recognition/`. During Phase 2, `freqid-core` will import from or adapt the PartialFace model and inference routines.
