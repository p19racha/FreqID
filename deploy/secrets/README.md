# FreqID Secrets Directory

This directory stores runtime cryptographic keys and credentials for the FreqID Docker Compose deployment.

## Security Requirements

1. **POSIX File Permissions**: All secret files in this directory must have permissions mode `0600` (`-rw-------`) and be owned by the user running Docker.
2. **Git Hygiene**: Real secrets are strictly excluded by `.gitignore` and git pre-commit safety hooks. Never commit `.key`, `.txt`, `.shares`, or unencrypted files from this directory to source control.
3. **Container Mounts**: The production `docker-compose.yml` mounts these secrets as read-only files under `/run/secrets/`.

## Required Secret Files (Generated by `deploy/scripts/init.sh`)

| File Name | Description | Generated By | Mode |
| :--- | :--- | :--- | :--- |
| `master.key` | 256-bit Base64-encoded root key for envelope encryption and HKDF subkey derivation. | `freqid_keys.py generate` | `0600` |
| `db_password.txt` | Secure random password for PostgreSQL `freqid` database user. | `openssl rand -hex 24` | `0600` |
| `jwt_secret.txt` | HMAC-SHA256 secret key for signing admin session tokens. | `openssl rand -hex 32` | `0600` |
| `backup.key` | Public key / passkey for encrypting automated database backups. | `openssl rand -hex 32` | `0600` |
